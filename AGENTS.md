## Reference website
- Keep the public reference markup and media snapshots in browser-safe data modules, with interactions owned by the React website component, to preserve the original public layout without contacting the source site's private services.
- Use the reference Button variant and centralized reference stylesheet tokens for original controls, so visual fidelity does not bypass the shared control component.
- Studio administration remains an external link to the original studio, and enquiries use an explicit email handoff until independent Cloud services are requested.
- Keep client and review layout overrides scoped in the global stylesheet after the reference import, so original snapshot styles remain intact and shared frame sizing stays consistent.
